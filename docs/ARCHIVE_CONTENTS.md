# Analysis archive contents

`Reproducibility.zip` contains analysis source code, fixed input manifests, derived result tables, the fifteen-sheet supporting results workbook and the five figures with their plotting data. `Pinned_Inputs.zip` supplies the fixed ClinVar file, ontology, disease annotations, gene-curation source, saved VCV examples and source-license records.

Publication documents and document-production tools are outside the scientific analysis release. Source inputs and results are separated so that code can be downloaded without transferring the large source files. SHA256 manifests identify exact files; the same canonical analysis archive can be used wherever a reproducibility bundle is requested.
